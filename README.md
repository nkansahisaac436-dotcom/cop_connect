## 📖 Overview

**COP Connect** is the official internal collaboration and capital project tracking intranet designed for **The Church of Pentecost (COP)** worldwide. 

The platform bridges the communication and oversight gap between **General Headquarters**, **Area Secretariats (Apostles)**, and **District Ministeriums (Pastors)** across all national and international fields. It transforms decentralized local progress into a transparent, unified national picture—tracking church auditorium constructions, mission houses, rural evangelism crusades, community boreholes, and youth development hubs.

## 🛡️ Hierarchical Trust Chain & Access Verification

COP Connect enforces a **2-Tier Strict Verification Hierarchy**. Access is strictly gated—there is **no open public registration**. All accounts require vetting by an ecclesiastical superior before activation:

```
[ General Headquarters ] (Super Admin)
         │
         │  Tier 1 Verification: Vets credentials & approves Area Heads
         ▼
[ Area Secretariat ] (Area Head / Apostle)
         │
         │  Tier 2 Verification: Vets credentials & approves District Ministers
         ▼
[ District Ministerium ] (District Pastor)
         │
         ▼  (Once verified & approved)
[ Active Ministerial Access: Project Publishing, Updates & Collaboration ]
```

### Role Matrix

| Role | Scope & Jurisdiction | Key Privileges & Responsibilities |
| :--- | :--- | :--- |
| **`SUPER_ADMIN`** | **General Headquarters** (National/Global) | • Oversee national project portfolio across all Areas<br>• Review and verify Area Head access requests<br>• Access full institutional audit logs & system metrics |
| **`AREA_HEAD`** | **Area Secretariat** (Single Area) | • Review and approve District Pastor access requests<br>• Monitor all district projects in their Area<br>• Publish area-level initiatives and missionary crusades |
| **`PASTOR`** | **District Ministerium** (Single District) | • Publish sanctuary constructions, outreaches, and welfare projects<br>• Update stage milestones (*Planned &rarr; Ongoing &rarr; Completed*)<br>• Upload progress photos and record financial stewardship |

## 🚀 Key Features

### 1. 📰 National Activity Feed & Capital Monitoring
- **Live Search & Discovery**: Filter instantly by Area, District, Category, and Completion Status.
- **Multi-Category Tracking**:
  - 🏛️ *Church Building & Sanctuaries*
  - 🏡 *Mission Houses & Quarters*
  - 🔥 *Outreach, Missions & Evangelism Crusades*
  - 💧 *Community & Social Welfare Projects (Boreholes, Clinics, Schools)*
  - 🎓 *Youth Development & Conferences*

### 2. 📸 Executive Project Composer & Milestone System
- **Camera & Photo Uploads**: Client-side canvas compression for high-speed uploads over mobile networks.
- **Milestone Checklist**: Step-by-step progress tracking with real-time status updates.
- **Financial Stewardship**: Target budget vs. raised funds tracking with multi-currency support (**GHS, USD, EUR, GBP**).
- **Status Progression**: Full audit trail with historical progress notes (*Planned &rarr; Ongoing &rarr; Completed*).

### 3. 💬 Ministerial Collaboration & Encouragement
- **Praises & Likes**: Ministers across sister districts can encourage local work.
- **Pastoral Commentaries**: Leave official feedback, prayer support, and congratulatory messages.

### 4. 📊 Leadership Dashboards
- **Headquarters Dashboard**: Aggregated national statistics, area-by-area performance, and pending Area Head approvals.
- **Area Head Dashboard**: Summary of all districts in jurisdiction, pastoral approval inbox, and financial totals.
- **Pastor Dashboard**: Quick project management, stage updates, and district profile.

### 5. 🗺️ National Directory & Profiles
- Comprehensive directory of Church Areas and constituent Districts across Ghana and international missions.
- Dedicated Area and District profile pages showing localized project portfolios.

### 6. 🌐 Multilingual Accessibility
- Full bilingual interface supporting **English** and **Français** for international missionary fields (West Africa, Europe, Americas).

## 🔒 Security Architecture

COP Connect is built for enterprise and institutional security:

- **Zero Seed Account Policy**: Shipped with **0 hardcoded credentials**, no mock users, and no bypass tokens.
- **First-Run Root Bootstrap**: The first user registering as `SUPER_ADMIN` initializes the General Headquarters root account. All subsequent users must be approved.
- **Enforced Login-First Gateway**: The application root navigation strictly verifies session validity (`12-hour TTL`). Unauthenticated users cannot access any dashboard, feed, or profile.
- **Cryptographic Password Hashing**: PBKDF2 with SHA-256 and unique per-user cryptographic salt via native **Web Crypto API**.
- **Brute-Force Lockout**: 15-minute automatic account lockout after 5 consecutive failed login attempts.
- **Two-Factor Authentication (2FA)**: Optional 6-digit TOTP verification challenge for leadership accounts.
- **Face ID Verification**: Required profile/portrait photo compression upon registration to prevent impersonation.
- **Comprehensive Audit Trail**: Administrative actions (`AREA_HEAD_APPROVED`, `PASTOR_APPROVED`, security events) are recorded with timestamps and actor IDs.

## 🛠️ Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**

### 1. Web Application

```bash
# Clone the repository
git clone https://github.com/nkansahisaac436-dotcom/cop_connect.git

# Navigate to the workspace
cd cop_connect

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)** (or your local Vite port) in your browser.

#### Production Build:
```bash
npm run build
```

---

### 2. Mobile Application (Expo Go / SDK 57)

```bash
# Start Expo development server from root
npm run mobile

# OR start with Tunneling (for remote testing on phone via Expo Go)
npm run mobile:tunnel
```

Scan the QR code displayed in your terminal using the **Expo Go** app on your iOS or Android device.
